# Mobile Mode MGK

Mobile-friendly interface module for [Foundry VTT](https://foundryvtt.com/) (v13 & v14) with touch controls, optimized drawer character sheets, chat log drawer, and performance tools.

Inspired 100% by `swipe-vtt`.

## Features
- **Canvas Touch Controls**: Tap to select/target, double tap to open sheets, 1-finger drag with wall collision check via `socketlib`, long-press for Token HUD, 2-finger pan & pinch-zoom.
- **Floating Controls Toolbar**: Quick access to macro hotbar, settings, dice roller, and chat log.
- **Avatar Carousel**: Bottom-center swipable character carousel.
- **Mobile Character Sheets**: Full-screen slide-up drawer for DnD5e (4.x/5.3+), PF2e, and System Agnostic.
- **Performance & Diagnostics**: Canvas freeze on idle, texture VRAM estimation (V14 multi-level API), image optimizer dialog.
- **MiniCanvas**: Lightweight 2D radar view for memory-constrained devices.

## Installation
Use this manifest URL in Foundry VTT:
```
https://github.com/<your-username>/mobile-mode-mgk/releases/latest/download/module.json
```
